# Security policy

## Reporting a vulnerability

Do not post exploit details, proof-of-concept code, credentials, or sensitive
logs in a public issue or discussion.

Use this repository's GitHub **Security** tab and choose **Report a
vulnerability** to submit a private report:

https://github.com/jangtrinh/omniact/security

If private reporting is unavailable, open a minimal public issue that requests
a private contact channel and omit all exploit details. The project does not
publish a security support status, response-time commitment, or email contact.
